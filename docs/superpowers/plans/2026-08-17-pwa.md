# PWA Instalável Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Transformar o BORA TREINAR em uma PWA instalável e offline-first, preservando a aplicação local-first e suas rotas hash.

**Architecture:** A PWA será adicionada sobre os arquivos existentes. O manifest e o Service Worker usarão caminhos relativos; o Service Worker fará precache do app shell, cache-first para assets e fallback de navegação para `index.html`. O registro ficará isolado no `js/app.js`, sem tocar na lógica de domínio ou no formato persistido.

**Tech Stack:** HTML5, CSS3, JavaScript ES Modules, Service Worker API, Web App Manifest, `localStorage`, Node.js built-in test runner e PowerShell/.NET `System.Drawing` apenas para gerar os PNGs oficiais.

## Global Constraints

- Usar somente HTML, CSS, JavaScript puro, ES Modules e `localStorage`; não adicionar frameworks, backend, banco remoto, TypeScript ou bundler.
- Preservar a chave `bora_treinar_state_v1`, rotas hash, treinos, sessões, histórico, progresso, configurações e importação/exportação JSON.
- Usar `Icone H.png` como fonte oficial; não redesenhar cores, símbolo ou identidade.
- Usar caminhos relativos para funcionar na raiz e em `/app-js-bora-treinar/`.
- O Service Worker deve limpar somente caches antigos pertencentes ao BORA TREINAR e nunca dados do usuário.
- Não alterar o design desktop sem necessidade; ajustes mobile devem ser mínimos e relacionados a safe areas/standalone.

- [ ] **Step 1: Criar a pasta e gerar os PNGs com a fonte oficial**

Usar PowerShell com `System.Drawing`, mantendo o conteúdo centralizado e proporcional; para o maskable, desenhar a fonte em 72% da área sobre fundo transparente, garantindo margem de segurança:

```powershell
$sourcePath = (Resolve-Path 'Icone H.png').Path
$source = [System.Drawing.Image]::FromFile($sourcePath)
$outputDir = Join-Path (Get-Location) 'icons'
New-Item -ItemType Directory -Force -Path $outputDir | Out-Null

function Save-Png($name, $size, $safe) {
  $bitmap = [System.Drawing.Bitmap]::new($size, $size)
  $graphics = [System.Drawing.Graphics]::FromImage($bitmap)
  $graphics.Clear([System.Drawing.Color]::Transparent)
  $graphics.InterpolationMode = [System.Drawing.Drawing2D.InterpolationMode]::HighQualityBicubic
  $graphics.SmoothingMode = [System.Drawing.Drawing2D.SmoothingMode]::HighQuality
  $drawSize = if ($safe) { [int]($size * 0.72) } else { $size }
  $offset = [int](($size - $drawSize) / 2)
  $graphics.DrawImage($source, $offset, $offset, $drawSize, $drawSize)
  $bitmap.Save((Join-Path $outputDir $name), [System.Drawing.Imaging.ImageFormat]::Png)
  $graphics.Dispose()
  $bitmap.Dispose()
}

Save-Png 'icon-192.png' 192 $false
Save-Png 'icon-512.png' 512 $false
Save-Png 'icon-maskable-512.png' 512 $true
Save-Png 'apple-touch-icon.png' 180 $false
Save-Png 'favicon-32.png' 32 $false
Save-Png 'favicon-16.png' 16 $false
$source.Dispose()
```

### Task 3: Implementar o Service Worker e seu registro

**Files:**
- Create: `service-worker.js`
- Modify: `js/app.js` (após a inicialização/renderização existente)

**Interfaces:**
- Consumes: app shell existente e `./manifest.webmanifest`.
- Produces: cache `bora-treinar-v1`, fallback offline e registro não bloqueante.

- [ ] **Step 1: Criar o Service Worker**

Adicionar:

```js
const CACHE_NAME = 'bora-treinar-v1';
const APP_SHELL = [
  './', './index.html', './manifest.webmanifest',
  './css/variables.css', './css/reset.css', './css/layout.css',
  './css/components.css', './css/responsive.css',
  './js/app.js', './js/data.js', './js/domain.js', './js/state.js',
  './js/storage.js', './js/ui.js',
  './icons/icon-192.png', './icons/icon-512.png',
  './icons/icon-maskable-512.png', './icons/apple-touch-icon.png',
  './icons/favicon-32.png', './icons/favicon-16.png',
];

self.addEventListener('install', (event) => {
  event.waitUntil(caches.open(CACHE_NAME).then((cache) => cache.addAll(APP_SHELL)));
});

self.addEventListener('activate', (event) => {
  event.waitUntil(
    caches.keys().then((keys) => Promise.all(
      keys
        .filter((key) => key.startsWith('bora-treinar-') && key !== CACHE_NAME)
        .map((key) => caches.delete(key)),
    )).then(() => self.clients.claim()),
  );
});

self.addEventListener('fetch', (event) => {
  if (event.request.method !== 'GET') return;

  if (event.request.mode === 'navigate') {
    event.respondWith(
      fetch(event.request).catch(() => caches.match('./index.html')),
    );
    return;
  }

  event.respondWith(
    caches.match(event.request).then((cached) => cached || fetch(event.request)),
  );
});
```
